# uemg-compras-databricks
Engenharia de dados aplicada a compras públicas: 2,1 milhões de registros do Portal de Compras MG processados no Databricks (Medallion + Unity Catalog) para analisar R$ 654 mi em compras da UEMG. Mostra economia nas licitações, aditivos, fornecedores e preços comparados ao Estado.
